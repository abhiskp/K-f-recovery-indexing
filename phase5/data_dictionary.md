# Phase 5 data dictionary

All counts are **30 m pixel centers**, not verified flood hectares. Approximate 30 m cell area is 900 m², but no candidate count is converted to inundation area. `NA` in reports means not measured/not executed, not zero. Empty string in CSV means unavailable source metadata; no imputation is made.

| File | Unit / time | Columns or codes |
|---|---|---|
| `data/processed/source_access_status.csv` | One source dataset/access lead; reviewed 8 Nov 2026 | `dataset` descriptive name; `custodian` agency; `source_url` primary public evidence; `public_evidence` what can be seen publicly; `local_source_file_status` whether actual underlying file is present; `needed_geospatial_file` requested deliverable; `minimum_missing_metadata` fields needed for use; `licence_status` permission state; `disposition` methodological use/gate. A public PDF is never marked obtained GIS data. |
| `data/processed/reference_evidence.csv` | One 2018 matched reference acquisition date in IST | `acquisition_date_ist` ISO local date; `reference_role` early/late pair; `independent_evidence` official rainfall/flood context; `spatial_temporal_limit` why it does not verify the scene pixel at 06:10 IST; `dry_status` always `unverified`; `source_url` primary source. |
| `data/processed/jrc_ee_console_transcription.json` | Earth Engine unweighted pixel-center reduction, 2014–17; **1,011,240** EE AOI cells | `annual[year][code]` integer cells for JRC `waterClass` 0=no data, 1=not water, 2=seasonal, 3=permanent, 255=source masked after `unmask`; `composite[code]` conservative four-year states defined in `composite_definitions`; `denominator_difference_pixels` is local Phase 4 minus EE reduction (370). These manually transcribed console outputs were checked against the downloaded raster: annual codes 0–3 agree exactly; each local year has 370 extra code-255 cells. |
| `results/phase4_water_valid_permanent_crosstab.csv` | Phase 4 2014–17 count bands; **1,011,610** local pilot cells | `valid_years` count 0–4 where source class >0, or `NA` for nonfinite bands; `permanent_years` count class-3 years or `NA`; `pixel_centers` integer; `fraction_of_pilot` denominator 1,011,610; `interpretation` warns that class-1 vs class-2 cannot be inferred from these two counts. |
| `results/reference_and_support_summary.json` | Phase 4 raster, pilot, 2018 pairs | Counts of pilot cells, finite/missing JRC count bands, overlap of early/late VV medians, late-minus-early fifth/median/95th percentile in dB, and number with absolute difference >3 dB. `reference_dry_status` is unverified. |
| `results/reference_candidate_overlap.csv` | 9 and 21 Aug 2018 separately, common Phase 4 strict support | `strict_support_pixels`; 3 dB candidate contingency `both_positive_pixels`, `early_reference_only_pixels`, `late_reference_only_pixels`, `neither_positive_pixels`; `candidate_union_pixels`; `candidate_jaccard_within_strict_support` = both/union; `no_water_exclusion_candidate_pixels` and `no_water_candidate_outside_strict_support_pixels` are sensitivity diagnostics. All are unvalidated rule outputs. |
| `results/jrc_annual_export_status.json` | File availability and QA at last audit run | `local_jrc_annual_geotiff_present` Boolean; `annual_class_spatial_map` `pending`/`executed`; local-versus-EE denominator difference, source-mask confinement Boolean, apparent alpha affected pixels, raw-band-reading Boolean, and local agreement counts versus Phase 4 count bands. |
| `data/raw/phase5_jrc_waterclass_2014_2017_pilot.tif` | Four 2014–17 JRC annual classes, 30 m EPSG:32643, 1111 rows × 921 columns | Bands `waterClass_2014`–`waterClass_2017`; Byte 0/1/2/3/255 codes as above. The fourth band is 2017 data, although GDAL tags it as alpha; use **raw** band values, not Rasterio `masked=True`. Sixty-five 2017 class-0 pilot values otherwise create a false mask on bands 1–3. |
| `results/jrc_annual_class_counts.csv` | Local exact Phase 4 grid, 2014–17 | `year`, `waterClass`, `class_name`, `pixel_centers`, `fraction_of_pilot`; denominator 1,011,610. Each year sums to the local pilot denominator. |
| `data/processed/jrc_composite_state_pilot.tif` and `results/jrc_composite_state_counts.csv` | Conservative four-year state, same 30 m grid | Code 0: <3 source-valid years; 1: all four class-1; 2: at least one class-2 with >=3 valid and <3 permanent; 3: >=3 class-3 and >=3 valid; 4: other mixed history with >=3 valid; 255: outside pilot/nodata. CSV has `state_code`, `state_name`, `pixel_centers`, `fraction_of_pilot`. These states are water-history descriptors, not flood truth or paddy labels. |
| `figures/phase5_support_reference_qa.png`/`.svg` | Map of fixed Alappuzha–Kottayam pilot in UTM km | Left: *count of years with known class from Phase 4 count band*, gray where count band absent. Right: 21 Aug unvalidated candidate agreement/disagreement between reference pairs, gray outside strict support. Figure is not validated inundation. |
| `figures/phase5_jrc_annual_classes.png`/`.svg` | Four annual JRC class maps of the same pilot | Separate codes 0, 1, 2, 3 and 255 for each year. Blank is outside pilot. Neither map is a 2018 inundation label. |

External input: `../phase4/data/raw/phase4_s1_2018_pilot_exploratory_candidate_bands.tif` is the original 45-band Float32 EPSG:32643 30 m export; its bands and missing-value semantics are in `../phase4/DATA_DICTIONARY.md`. The Phase 3 rice panel (`../phase3/data/processed/district_season_rice_2014_2020.csv`) is referenced only as a future outcome source and was not joined or modified in Phase 5.
