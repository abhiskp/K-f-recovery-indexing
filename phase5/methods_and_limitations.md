# Methods and limitations

## Executed method

Phase 5 uses the independent Phase 4 audit as an evidence gate. We reviewed official NRSC/KSDMA/IMD/CWC source pages and the Bhuvan viewer's recorded layer reference, maintaining source URL, custodian, local-file status, licence and missing metadata in `data/processed/source_access_status.csv`. We did not digitize cartographic PDFs as truth. The public duration map's class legend and four RADARSAT-2 dates were transcribed as **source metadata**, not geospatial observations.

For local numerical QA, `scripts/audit_reference_and_jrc.py` reads the unmodified Phase 4 45-band GeoTIFF. It rasterizes the fixed pilot rectangle onto that GeoTIFF's EPSG:32643, 30 m grid, counts pixel centers, treats nonfinite water-history count bands as missing, cross-tabulates valid/permanent 2014–17 years, and compares the two pre-event VV median reference pairs. It evaluates already-frozen Phase 4 3 dB candidate masks on the **same strict support** and reports their overlap/Jaccard. No new threshold is fitted. The plotting script maps count-band availability and reference disagreement, with unsupported pixels explicit. NumPy percentile output and the binary-mask contingency are deterministic; no random seed is used.

Separately, authenticated Earth Engine Code Editor runs used `JRC/GSW1_4/YearlyHistory` for 2014–17. `gee_jrc_yearly_audit.js` was executed to submit a four-band `waterClass` GeoTIFF export and print four *weighted* frequency histograms; these fractional histograms are not reported as cell counts. `gee_jrc_integer_counts.js` then executed `ee.Reducer.frequencyHistogram().unweighted()` on the specified UTM grid to obtain the integer counts preserved in `data/processed/jrc_ee_console_transcription.json`. Source class 0 (no data) is separate from 255 (source mask after unmasking). The downloaded GeoTIFF passed exact CRS/transform/shape checks against Phase 4. The Code Editor reduction includes 1,011,240 cells and the local Rasterio AOI includes 1,011,610; all 370 additional local cells are code 255 in every year. Codes 0–3 and all known composite states agree exactly across denominators. The script creates a conservative four-year state raster and local counts; `plot_jrc_annual_classes.py` maps annual classes. GDAL mislabels the fourth Byte band as alpha, so the audit reads raw values and explicitly checks its 65 class-0 pilot cells rather than accepting an automatic mask.

## Limits of interpretation

1. **No independent flood labels:** The official 21 August GIS layer reportedly exists at KSDMA, but is not held here. The public WMS/PDF cannot define surveyed negatives or the real source footprint. Confusion scores and flood area are withheld.
2. **Duration is not recovery:** Map ID 2018/14 classifies within-event inundation duration from RADARSAT-2 dates. Its method and gaps are unknown and it has no ground verification in the public PDF. It could later serve as hazard severity, not post-event return to function.
3. **Reference dryness:** Rainfall narratives are regional/temporal context, not local 06:10 IST dry labels. The 10/22 June and 4 July scenes remain unverified. The two reference medians share 22 June, and their difference cannot isolate any one date or flood process.
4. **Backscatter confounding:** Rice crop stage, wet soil, water roughness/wind, seasonal ponding, vegetation, buildings, speckle, and layover/shadow can affect VV backscatter. A threshold-positive cell is not a flood observation. Orbit matching and low-slope screening do not remove these causes.
5. **JRC incompleteness:** Annual classes derive from Landsat long-term seasonality, not a contemporaneous 2018 field map. More than 63% of pilot centers have no finite history count band in Phase 4; explicit 0 and source masked 255 remain unknown. Stable not-water screening would omit much seasonally wet paddy area. Original strict and alternate masks have different supports and cannot be compared as flood area.
6. **Source dependence:** The NRSC 21 August layer uses RADARSAT-2, a different sensor from our Sentinel-1 candidate, but may share mapping rules/ancillary data. The duration layer includes the same RADARSAT-2 21 August source; the two are not independent test sets. Other NRSC/Bhuvan maps partly use Sentinel-1.
7. **Outcome scale:** Phase 3 rice area/production/yield are district-season totals, not geolocated pixel outcomes. No licensed 2018 cultivated-rice polygon or exposure-to-outcome join is present. Optical/VIIRS monsoon availability was weak in Phase 4, so no ecological/economic proxy recovery is inferred.
8. **Access and licence:** NRSC's PDF says the layer was transmitted to KSDMA, not that it is public or licensed for redistribution. KSLUB describes a request and payment procedure. Our shell's DNS could not access the NRSC PDF URL, and a browser request for the duration WMS capabilities was blocked by the client. Official web pages remained readable through search. Neither technical access error proves the underlying data unavailable.

`validation_protocol.md` specifies what would be measured only after source and licence checks. The current **NO-GO** is an evidence assessment, not a claim that recovery is absent.
