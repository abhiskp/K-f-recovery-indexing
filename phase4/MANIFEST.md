# Phase 4 file manifest

[`results/file_manifest.csv`](results/file_manifest.csv) lists every non-generated Phase 4 file, its purpose, byte count and SHA-256 digest. [`results/checksums.csv`](results/checksums.csv) is a compact checksum-only version. Both are regenerated by `python3 phase4/scripts/make_manifest.py` from the project root. The two generated manifest CSVs exclude themselves to avoid a circular hash.
