# Decision gate for the recovery-priority hypothesis

## Established by executed Phase 3 work

- A reproducible **252-row official district-season-year rice panel** and source-level QA audit now exist.
- The official state 2018–19 year-over-year pattern is reproduced: Autumn −31.54%, Winter +27.68%, Summer +28.23%, annual +10.92% production.
- A four-year same-season reference shows 2018–19 state Autumn production −36.13%, Winter +30.25%, and Summer +37.55%. Eleven of 13 districts with a positive Autumn reference fell below it; substantial variation remained in 2019–20.
- The 2019–20 compendium has material district-season errors, corrected in the processed panel from the original annual report. The corrected source and checks are retained, not silently overwritten.

## Not established

- **Flood-attributable agricultural recovery**, recovery duration, or a causal cumulative deficit.
- A validated 2018 georeferenced inundation/depth layer covering the chosen agricultural units.
- Ecological, economic, housing or infrastructure return to functioning.
- A scientifically justified multidimensional recovery-priority score, changed rankings due to actual recovery, or improved prioritisation against independent outcomes.

**Decision: NO-GO** for claiming a tested recovery-adjusted vulnerability ranking or superior prioritisation. The seasonal analysis supports a narrower paper finding: annual production obscures a post-event autumn decline and district heterogeneity. It does not prove which districts suffered flood-caused prolonged recovery.

## Access and evidence needed next

1. **Earth Engine:** the researcher should sign into a Google account at [Earth Engine Code Editor](https://code.earthengine.google.com/), with access to a Cloud project registered for Earth Engine, API enabled and appropriate project permissions. If the project does not exist, follow [Google's registration and access steps](https://developers.google.com/earth-engine/guides/access). Share the project ID and confirmation that the Code Editor can run Sentinel-1 queries, or run the included script and supply the GeoTIFF plus metadata CSV. Do **not** send a password, OAuth token or private key.
2. **Independent flood labels:** obtain dated georeferenced 2018 inundation/depth polygons, raster or the KSDMA crowdsourced point observations from KSDMA/NRSC, with licence, accuracy and coverage metadata. The publicly viewed PDF maps do not provide the same validation utility. [NRSC's rapid map](https://ndem.nrsc.gov.in/documents/Disaster_Document/2018/KL/klflood50dsc21082018_1830hrs/klflood50dsc21082018_1830hrs_map.pdf) explicitly covers only part of Kerala on one date.
3. **Functional recovery:** stable local-unit seasonal crop data and dated road, housing or essential-service restoration records, ideally with later-event outcomes. For a future-event validation, freeze predictor data before that event and reserve separate locations and time periods for testing.

The current 2026 vulnerability comparator can be used only for a clearly labeled **retrospective** rank comparison. Before any composite, its adaptive-capacity sign and source timing must be reconciled; weights and normalisation should be fixed for substantive reasons and checked for stability, not selected to maximise rank changes.
