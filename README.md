# Kerala flood recovery and vulnerability rankings

Research project: **Beyond Flood Risk: Does Accounting for Post-Flood Recovery Change Vulnerability Rankings in Kerala?**

The inherited manuscript, data, and agricultural ranking experiments are in `Kerala_Flood_Recovery_Codex_Package_Fixed(1)/`. The `phase2/` directory contains the Phase 2 audit, reproducible local agricultural analyses, outputs, and an **unexecuted** Google Earth Engine pilot script. Satellite recovery measurements and a flood-attributable multidimensional ranking have not yet been produced.

Start with [REPRODUCTION.md](REPRODUCTION.md) for commands and dependencies, [EXPERIMENT_SUMMARY.md](EXPERIMENT_SUMMARY.md) for completed findings, and [DATA_DICTIONARY.md](DATA_DICTIONARY.md) for dataset fields. [MANIFEST.md](MANIFEST.md) records checksums from the Phase 2 handoff snapshot. The ZIP handoff itself is intentionally excluded from this repository.

No new experiments were run while preparing this repository.
